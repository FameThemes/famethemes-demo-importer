# AGENTS.md — FameThemes Demo Importer

Rules and invariants for any AI coding agent working on the FameThemes Demo Importer plugin. Agent-agnostic: applies to Claude Code, Cursor, Codex, or a human contributor.

Detailed how-it-works references live in [`docs/`](docs/). This file is **rules only** — concise, enforceable, no narrative.

---

## 1. Project at a glance

- WordPress plugin that ships templates ("demo content") into a live site. Renders a wizard, downloads assets from a Studio server, runs a 5-phase cron-driven import pipeline.
- **Two tracks**, picked at boot from the active theme slug:
  - **Legacy track** (`inc/legacy/`) — synchronous AJAX importer for the OnePress family (`onepress`, `screenr`, `accelerate-*`, `onepress-*`). Frozen — no new features.
  - **Generic track** (`inc/generic/`) — background-job pipeline with React UI. Default for every other theme. **All new work goes here.**
- Stack: PHP 7.4+, `@wordpress/scripts` (webpack 5), no Grunt.
- React UI built from `src/generic/` → `inc/generic/build/`.

---

## 2. Quick start

```bash
pnpm install
pnpm build
```

`pnpm start` for watch mode. Build artifacts (`inc/generic/build/`) ARE committed for deploy convenience.

## 3. Hard rules

### 3.1 Never touch the Legacy track

Files in `inc/legacy/` are frozen for backward compatibility with thousands of OnePress installs. Bug-fixes only, no refactors. New features land in `inc/generic/` only.

The track is chosen in [`famethemes-demo-importer.php`](famethemes-demo-importer.php) via `demo_contents_is_legacy_theme()`. Adding a theme to the legacy list is forbidden — new themes use the Generic track with a Theme_Adapter.

### 3.2 Never invent a new theme_mod / wp_options key without an adapter

The importer writes user data into the live site. New storage keys mean every site running the plugin gets a new row. Always:

1. Reuse existing theme keys when possible (e.g. Customify's palette slots).
2. Funnel anything new through `Theme_Adapter` — never hard-code key writes in pipeline steps.
3. Add to the denylist in `Options_Importer::DENIED_KEYS` (extensible via the `ft_demo_importer_denied_option_keys` filter) when an option doesn't round-trip cleanly (e.g. `site_icon`).

See [`docs/SPEC-adapter.md`](docs/SPEC-adapter.md).

### 3.3 Never break the Generic / Customify boundary

Code lives in one of three zones:

| Zone | Knows about |
|---|---|
| `inc/generic/` (excluding `Adapters/`) | Generic contract only — theme-agnostic |
| `inc/generic/Adapters/class-*-adapter.php` | One specific theme |
| `inc/generic/Adapters/customify/*` | Customify-specific helpers (Font_Installer) |

A class in `inc/generic/Jobs/` referencing `customify_*` functions is a structural defect. Customify-specific behaviour goes into `Customify_Adapter::after_phase()` hooks, never into the runner or step classes.

### 3.4 Job runner abort semantics

`Importer_Runner` runs 5 phases under WP-Cron. Rules:

| Failure | Behaviour |
|---|---|
| Required plugin fails to install/activate | Abort job (status → `failed`). |
| Recommended plugin fails | Log + continue. |
| Content import fails (terms/posts/menus) | Abort. |
| Options import fails | Abort. |
| Font Library install fails (WP < 6.5, network) | Log + continue — theme_mods still written, font resolver falls back to Google CDN. |

When changing phase logic, walk through these branches in [`Importer_Runner::run()`](inc/generic/Jobs/class-importer-runner.php) and make sure the new code respects the same contract.

### 3.5 REST surface is public

REST namespace `ft-demo-importer/v1` is consumed by the React UI. Renaming a route or changing payload shape is a breaking change. Add new routes alongside; deprecate old ones via WP's REST `_deprecated_argument` pattern.

Routes:

| Method + Path | Owner |
|---|---|
| `GET /studio/me` / `templates` / `templates/{id}` / `categories` | `Studio_Proxy_Controller` |
| `POST /theme/jobs` / `GET /theme/jobs/latest` / `GET /theme/jobs/{id}` / `POST /theme/jobs/{id}/cancel` | `Job_Controller` |

All routes gate on `manage_options` + `X-WP-Nonce`. Never weaken this.

### 3.6 Activation hook silent on non-interactive contexts

`activated_plugin` in [`famethemes-demo-importer.php`](famethemes-demo-importer.php) MUST bail (no `wp_safe_redirect`) when:

- `REST_REQUEST` is true (REST clients expect JSON, not 302)
- `DOING_AJAX` is true
- `DOING_CRON` is true
- `WP_CLI` is true

The wp-admin Plugins screen still gets the redirect. Breaking this returns "invalid JSON response" to any host that activates via REST (the Customify dashboard one-click activator does this).

### 3.7 React bundle is build-step output

Edit `src/generic/`, never `inc/generic/build/`. `build/` is committed for deploy but regenerated by `pnpm build`. After source change, always rebuild — stale `build/admin.js` shipping to production silently breaks the wizard.

### 3.8 i18n

Every user-visible string in PHP MUST use `__()` / `_n()` / `_x()` against text domain `famethemes-demo-importer`. Numbered placeholders (`%1$s`, `%2$d`) when there's more than one arg. `/* translators: */` comments on each call.

For JS: import `__` from `@wordpress/i18n` and same text domain.

### 3.9 Studio credentials priority

The credential chain in [`Options_Store::studio_url()`](inc/generic/Settings/class-options-store.php) is:

1. `FT_DEMO_IMPORTER_STUDIO_URL` constant (wp-config)
2. `wp_options` row (`ft_demo_importer_studio_url`)
3. Active adapter's `studio_server_url()`
4. Plugin default

Never let an adapter override the wp-config constant — adapters are defaults, not authorities. The bridge in [`bootstrap.php`](inc/generic/bootstrap.php) enforces this; don't regress it.

### 3.10 Embed contract

When the importer is hosted inside another theme's dashboard (Customify is the first), the contract is:

- Host page enqueues the importer's React bundle via `wp_enqueue_script` on the host hook (`Generic_Dashboard::enqueue_assets()` adds the host hook automatically when the adapter declares `embed_host_hook()`).
- Adapter sets `embedded: true` in the localize → `src/generic/admin.js` skips auto-mount.
- Host calls `window.ftDemoImporter.mount(el)` / `unmount(el)` on its own component lifecycle.

The host MUST drive mount/unmount; the bundle never auto-mounts in embedded mode. See [`docs/SPEC-embed-contract.md`](docs/SPEC-embed-contract.md).

### 3.11 English only

All code comments, docblocks, inline notes, `.md` files, commit messages must be English. Conversation with the user is unconstrained.

### 3.12 Filter the Studio response shape, don't trust it

The Studio server is operationally separate. Parsers (`TemplateGrid.jsx`, `class-content-importer.php`, `class-options-importer.php`) must tolerate:

- Bare array OR `{items:[]}` envelope
- Bare array OR `{categories:[]}` envelope
- Pagination at `meta.total` OR root `total`
- Missing fields → safe defaults, no throws

When in doubt, add fallback parsing.
